# Contributing to the Windows platform

Use the repository's root `CONTRIBUTING.md`, `AGENTS.md` and safety documentation.
Build with `dotnet build platforms/windows/Usbless.Windows.csproj -c Release`.
Storage, firmware and cleanup tests belong in disposable marked VMs.

Keep required copyright and license notices. Product copy and artwork use the USBless brand.
Record preparation, installation, preservation and recovery evidence separately.
