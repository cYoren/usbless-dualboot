usbless-dualboot — read-only companion

Validates a probe document, summarizes the detected layout, compares a proposed plan against it, and explains the risk. It reads only the files you select below.

This tool cannot change your machine. It performs no disk discovery, needs no root, runs no command, opens no network connection, and exposes no port. Every capability is read-only and built from pure functions. The CLI's mutating phases are not implemented here — to actually shrink, stage, or alter boot entries you must run usbless-dualboot yourself in a terminal, after reviewing its own --dry-run output.
